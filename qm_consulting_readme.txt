일학습병행 품질관리 컨설팅 가이드 · 목차 반응형 수정본 v2.8
2026.10.22. / 사용자 매뉴얼 및 지원단 운영안내 반영

1. 열기
qm_consulting_index.html을 PC·모바일 브라우저 또는 앱 내 브라우저에서 엽니다.
목차, 본문 검색, 이전·다음 이동, 글자 크기 조절, 인쇄를 사용할 수 있습니다.
별도 앱 설치 없이 반응형 화면으로 읽는 웹 이북입니다.

2. PDF와 별첨
qm_consulting_guide.pdf: 전체 가이드 32쪽
attachments/qm_consulting_system_manual.pdf: 일학습병행 품질관리 운영시스템 사용자 매뉴얼(원본)
attachments/qm_consulting_checklist_center.pdf: 공동훈련센터용 체크리스트(원본)
attachments/qm_consulting_checklist_company.pdf: 학습기업용 체크리스트(원본)
qm_consulting_preview.png: 게시용 미리보기 이미지
로고 4종·표지 배경·홈페이지 및 운영시스템 QR코드는 qm_consulting_index.html 안에 포함되어 있습니다.
별도 이미지 폴더를 업로드할 필요가 없습니다.
qm_consulting_preview.png는 링크 공유 미리보기용으로 유지하며, 가이드 본문 화면은 이 파일 없이도 표시됩니다.
표지·목차·본문의 쪽수는 전체 PDF 기준입니다.

3. 게시
게시용 파일은 qm_consulting_index.html, qm_consulting_guide.pdf, attachments/의 PDF 3종입니다.
링크 공유 미리보기를 사용하려면 qm_consulting_preview.png도 함께 올립니다.
이 폴더의 구조를 유지한 채 파일을 정적 웹호스팅에 올립니다.
게시 후 사이트 주소 뒤에 /qm_consulting_index.html을 붙여 접속·공유합니다.
본문 HTML은 qm_consulting_index.html 하나이며 별도 연결용 index.html은 사용하지 않습니다.
모바일에서 직접 파일을 열 수 없는 앱은 게시된 URL을 이용합니다.
브라우저·앱에 따라 다운로드 대신 PDF 보기·저장 메뉴가 열릴 수 있습니다.

4. 수정
수정용 원고·제작 스크립트·제작 검토 메모는 별도 제작자료로 보관합니다.
이미지 원본은 별도 제작자료에 보관하고, 게시용 HTML에는 원본 이미지를 그대로 포함했습니다.
게시용 HTML·PDF·첨부·미리보기·안내 파일명에는 qm_consulting_ 접두사를 붙였습니다.
게시용 묶음에는 웹 열람·PDF·별첨 다운로드와 공유 미리보기에 필요한 파일을 포함했습니다.

5. 목차 표시 보완
창 크기를 변경해도 왼쪽 목차의 쪽수는 오른쪽 고정 칸에 표시됩니다.
제목 크기는 목차 폭에 맞춰 조정됩니다. 아주 좁은 화면에서 생략된 제목은 마우스를 올려 전체 내용을 확인할 수 있습니다.
